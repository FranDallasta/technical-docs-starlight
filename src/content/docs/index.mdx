## About This Documentation

This is a comprehensive documentation website for the **Ghost CMS** platform, built with [Starlight](https://starlight.astro.build) and following the **Diataxis** methodology for technical documentation.

### What is Diataxis?

This documentation follows the **Diataxis framework**, a systematic approach to technical documentation that organizes content into four distinct types:

- **Tutorials** - Learning-oriented guides that help users accomplish a specific task
- **How-to Guides** - Problem-oriented instructions for solving specific problems  
- **Technical Reference** - Information-oriented descriptions of the machinery
- **Explanation** - Understanding-oriented discussions that clarify a topic
